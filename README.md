# ☕ Coffee Shop App - Architecture & Flow Map

This document outlines how the different files in this project interact, reflecting our new modular database architecture and dark-themed UI.

## 1. 🚀 The Startup Flow (How the app boots up)

* **`backend/venv/Scripts/activate`** ---> Activates the isolated Python environment.  
* **`uvicorn main:app --reload`** ---> Boots up the FastAPI backend on port 8000. Generates `coffee_shop.db` automatically if missing.  
* **`npm run dev`** ---> Boots up the Next.js frontend on port 3000.

## 2. 🔄 The Data Flow (How Frontend talks to Backend)

* **1. Browser** ---> User visits `http://localhost:3000` ---> Calls `frontend/app/page.tsx`.  
* **2. `frontend/app/page.tsx`** ---> Executes `fetch("http://localhost:8000/menu")` ---> Reaches out to the backend.  
* **3. `backend/main.py` (CORS)** ---> Intercepts the request ---> Checks `CORSMiddleware` ---> Permits traffic from port 3000.  
* **4. `backend/routers/menu.py`** ---> Takes over the route `@router.get("/menu")` ---> Injects a temporary database session via Dependency Injection.
* **5. Database Query** ---> Queries `models.DBMenuItem` ---> Fetches raw data from the local SQLite file.
* **6. `backend/schemas.py`** ---> Validates the outgoing data as a Pydantic `MenuItem` ---> Converts it safely to JSON.  
* **7. `frontend/app/page.tsx`** ---> Receives JSON data ---> Bakes the menu items into the Card component ---> Renders the final HTML.  
* **8. Browser** ---> Displays the fully rendered dark-themed page to the user.

## 3. 📂 Directory Map & File Purposes

### 🟢 The Backend (`/backend`)

* **`main.py`** ---> The Entry Point ---> Wires up CORS, initializes the database tables, and attaches our modular routers.
* **`database.py`** ---> The Infrastructure ---> Manages the SQLAlchemy SQLite engine, connection pooling, and session factories.
* **`models.py`** ---> The Data Layer ---> Contains SQLAlchemy classes that define the exact columns and constraints of the physical SQLite tables.
* **`schemas.py`** ---> The Bouncer ---> Contains Pydantic classes that validate inbound HTTP data and format outbound JSON to keep internal DB structures secure.
* **`routers/`** ---> The Controllers ---> A folder containing isolated endpoint logic (like `menu.py`) to keep the main application clean.
* **`coffee_shop.db`** ---> The Vault ---> The local SQLite database file generated by SQLAlchemy (ignored by Git).
* **`venv/`** ---> The Engine Room ---> Holds isolated FastAPI/Uvicorn installations ---> Prevents system-wide Python conflicts.

### 🔵 The Frontend Configuration (`/frontend`)

* **`package.json`** ---> The Blueprint ---> Tracks JS dependencies (React, Next.js) ---> Tells Node.js what to install/run.  
* **`components.json`** ---> The shadcn Compass ---> Configures UI paths ---> Tells the CLI where to drop new components (like cards and buttons).  
* **`next.config.ts`** ---> The Next.js Engine Settings ---> Configures the server ---> Controls caching behavior and strict rules.  
* **`tsconfig.json` & `eslint.config.mjs`** ---> The Code Police ---> Enforce strict TypeScript typing and syntax rules ---> Catch bugs in VS Code before saving.

### 🟣 The UI Layer (`/frontend/app` & `/frontend/components`)

* **`app/layout.tsx`** ---> The Master Wrapper ---> Defines the `<html>` and `<body>` skeleton ---> Injects the Inter font and forces the global `dark` theme.  
* **`app/page.tsx`** ---> The Active Canvas ---> Fetches backend data and imports components ---> Renders the homepage.  
* **`app/globals.css`** ---> The Paint Bucket ---> Stores base Tailwind variables (like background and foreground colors) ---> Adapts automatically based on the active theme.  
* **`components/ui/card.tsx` & `button.tsx`** ---> Reusable UI Building Blocks ---> Imported into `page.tsx` ---> Render the visual interfaces.  
* **`lib/utils.ts`** ---> The Toolbox ---> Contains the `cn()` function ---> Called by UI components to cleanly merge Tailwind CSS classes.
